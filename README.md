# MC102
# Algoritmos e Programação de Computadores

Exercícios e programas em Python feitos na disciplina MC102 na Unicamp
(Engenharia de Computação, 1° semestre).

## Conteúdo

| `tarefa05` | Utiliza tuplas e testa funções |
| `tarefa06` | Chama funções e abre arquivos |
| `tarefa07` | Otimiza a passagem por matrizes |
| `tarefa08` | Usa dicionário pra gerenciar arquivo |
| `tarefa10` | Funções e recursão, otimizando o código |

## Como rodar

Precisa do Python 3 instalado. Dentro de uma pasta:

```
python nome_do_arquivo.py
```

## O que aprendi

- lógica de programação e decomposição de problemas
- manipulação de listas e strings
- escrever funções reutilizáveis e usar recursão
- otimizar busca de matrizes
